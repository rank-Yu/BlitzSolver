# run-eval

整局评估器：用离线宿主批量跑整局，比较局外策略，不参与求解器构建。

## 职责

- **多进程**：父进程生成种子集与策略配置，每个工作进程跑一局（独立进程，避免原版静态状态
  跨局污染）。
- **种子集**：放在 `tests/corpora/runs/`；每个种子固定角色、进阶、解锁状态与是否应用教学
  重排，保证可复现。
- **配对比较**：同一批种子下，两套策略各跑一次；按种子配对，比较胜负、楼层、金币、牌组、
  遗物与决策结果。
- **报表**：按角色、进阶、幕分组；输出每组的局数、胜率、均值与配对差值，并保留逐局明细。

## 边界

- 运行原版整局，战斗交给 Blitz；不自己实现局外推进。
- 只读原版状态；策略代码不读随机数状态或未来生成序列。
- 评估器不进入 `BlitzSolver.sln`；R5 落地。

R3-0 只写职责，不建项目文件。
